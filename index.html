    导出

    把全部记忆下载成一个压缩包。解压后的结构和桌面上的「另一个我」文件夹一致：每段记忆一个 Markdown 文件，另有一份完整的 JSON、全部录音和照片原件。

    云端不等于备份。建议每月导出一次，放进桌面的文件夹，再复制到移动硬盘。

    检验完整性
    
        
    
          
    压缩包里有一份 MANIFEST.sha256，记录了每个文件的校验码。解压后在终端运行下面这行，每一行显示 OK，就说明一个字节都没有丢。
    
        
    
        
    cd 另一个我 && shasum -a 256 -c MANIFEST.sha256
    
      
    

      
    
        
    谁能看到
    
        
    
          
    记忆存在你自己的 Supabase 数据库里。数据库开启了行级权限：只有登录你的账号，才能读写你的记忆和素材。每台登录过的设备上还有一份副本，所以断网时也能写，联网后自动同步。
    
          
    每段记忆还标着访问范围：仅自己、留给家人、交给另一个我。导出包会保留这些标记；交给 AI 之前，请先删掉标为「仅自己」的文件。
